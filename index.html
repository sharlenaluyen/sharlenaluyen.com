Google Workspace MCP servers, multi-account, and safe by default

Four local MCP servers that let Claude work across several Google accounts at once: Gmail, Calendar, Drive, and Docs/Sheets/Slides. Plus, one shared accounts package to let each account sign in once and every server use it.

  • Dry run before anything others see. Sends, shares, invites, overwrites, and deletes return a preview (recipients, before/after diffs, who gets emailed) and it only acts on an explicit confirm. Gmail replies can only ever land as drafts (never sent).
  • Least-privilege OAuth. Drive defaults to drive.file, whole-Drive read is a per-account opt-in, and each tool checks only the scope it needs, with errors that name the exact fix.
  • Built for shared state. Lock-filed atomic writes to the token store, an append-only audit log that never records content, retries only on idempotent calls, and a file sandbox that rejects ../ and symlink escapes.
  • Node.js
  • MCP SDK
  • Google APIs
  • OAuth 2.0
  • node:test

Leads dashboard: Gmail-synced outreach with Claude-drafted follow-ups

A locally run dashboard over outreach spreadsheets. For every lead, it shows when you last emailed (in either direction), whether it's your turn, a 0–3 priority, and a follow-up status. Tick rows and Claude drafts follow-ups straight into Gmail as drafts; it never sends.

  • Gmail is the source of truth for email and the sheet is the source of truth for leads. Sync writes only changed cells, and SQLite holds bookmarks that can be rebuilt any time.
  • Reuses the MCP servers' sign-in, Gmail helpers, and audit log. Write-back to sheets is off until you turn it on, and edits have history & undo.
  • Node.js
  • SQLite
  • Gmail & Sheets APIs
  • Claude Code

Dodgers & LAFC win alerts for food deals

Push notifications when the Dodgers win at home or LAFC scores first in the first half at home (each unlocks a food promo), once right away and again the next morning. A Cloudflare Worker on cron triggers polls the MLB Stats API and ESPN's play-by-play, then publishes through ntfy.

  • Traced dropped alerts to ntfy.sh's per-IP rate limit on Cloudflare's shared egress, wrote it up upstream, and moved to a self-hosted ntfy on Cloud Run's free tier.
  • An integration registry, KV de-duplication, and a deduped ops page when the unofficial ESPN API changes shape, so it never fails silently.
  • JavaScript
  • Cloudflare Workers & KV
  • Cloud Run
  • ntfy
